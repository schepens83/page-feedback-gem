Page feedback gem · /feedback/review/exports · 2026-11-07

Paginate the review exports list

The exports history now shows 20 exports per page, newest first, with Newer / Older links. A small Pager object does the arithmetic so neither the controller nor the view has to.

How it flows

GET /exports?page=N→ExportsController#index→Pager→offset/limit query→View: Newer / Older

Where it lives

app/models/page_feedback/pager.rbTurns a raw page param and a total into a clamped page, offset, limit and neighbouring page numbers.
review/exports_controller.rbCounts exports, builds the pager, applies offset and limit (ties broken by id).
exports/index.html.erbRenders the nav only when there is more than one page.

Why this shape

  • A plain object instead of a pagination gem: the gem adds no dependency, and this is the only list that needs it.
  • Bad input never errors: junk or zero becomes page 1, too large becomes the last page.

Proof

  • spec/models/page_feedback/pager_spec.rb: clamping, offsets, neighbours.
  • spec/requests/exports_spec.rb: two pages, newest first, links, lenient params.
